# RGA NeuroMatrix™ Incident Management System

## Overview

The RGA NeuroMatrix™ Incident Management System is a proprietary incident quality, workforce capability, training and AI\-enabled framework designed for the Australian NDIS sector.

The system is being developed to help NDIS providers:

- Improve incident report quality
- Improve workforce competency
- Improve documentation consistency
- Improve audit readiness
- Strengthen incident management processes
- Reduce compliance risk
- Develop organisational capability

---

## Vision

To become the leading incident quality and incident capability framework used by NDIS providers across Australia.

---

## Core Intellectual Property

### RGA™ Incident Report Quality Matrix

A structured quality assessment framework designed to evaluate incident reports through multiple quality dimensions.

### RGA TRACE™

A practical writing framework that guides support workers through high\-quality incident documentation.

### RGA S.A.F.E.R.™

A first\-response framework focused on immediate actions following an incident.

### Three\-Lens Model™

An incident quality model focused on:

1. Writer
2. Reviewer
3. Manager

### PIMA™

Provider Incident Management Assessment Framework.
