# Methodology

## Purpose

This folder contains the core intellectual property (IP) of the RGA NeuroMatrix™ Incident Management System.

The methodology forms the foundation for:

- Digital Products
- Training Programs
- Assessments
- AI Solutions
- Future SaaS Development

All products and services within the ecosystem trace back to the methodology contained in this folder.

---

## Core Methodology Assets

### RGA™ Incident Report Quality Matrix

The primary quality assessment framework used to evaluate incident report quality.

### RGA™ Indicator Dictionary

Defines all scoring indicators, quality criteria and reviewer guidance.

### RGA™ Calibration Library

Official scoring examples used for training, quality assurance and AI evaluation.

### RGA TRACE™

The frontline incident report writing framework for support workers.

### RGA S.A.F.E.R.™

The immediate response framework for incident management.

### RGA Three-Lens Model™

Quality assurance model covering:

1. Writer
2. Reviewer
3. Manager

### PIMA™

Provider Incident Management Assessment Framework.
