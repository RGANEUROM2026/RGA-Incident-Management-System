# Calibration Library

Status: Complete

## Purpose

The Calibration Library serves as the official training, calibration and benchmarking resource for the RGA™ Incident Report Quality Matrix.

Its purpose is to:

- Standardise scoring
- Improve reviewer consistency
- Support assessor calibration
- Support training delivery
- Support AI evaluation
- Support future SaaS validation
