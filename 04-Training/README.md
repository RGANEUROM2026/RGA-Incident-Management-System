# Training

## Purpose

This folder contains all training, assessment and competency development materials associated with the RGA NeuroMatrix™ Incident Management System.

The objective is to help workers, reviewers and managers develop practical incident reporting capability rather than simply complete compliance training.

---

## Training Programs

### Program 01

Worker Training Program

Target Audience:

- Support Workers
- Disability Support Professionals
- SIL Workers
- Community Support Workers

Modules:

- Understanding Incidents
- First Response
- TRACE™ Framework
- Objective Documentation
- Participant Voice & Dignity
- Escalation Pathways
- Incident Writing Practice

Status: Planned
